# Editor Markdown

[![HTML](https://img.shields.io/badge/HTML-5-orange)](https://developer.mozilla.org/pt-BR/docs/Web/HTML)
[![CSS](https://img.shields.io/badge/CSS-3-blue)](https://developer.mozilla.org/pt-BR/docs/Web/CSS)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript)

Editor markdown com preview em tempo real e parser implementado do zero (sem bibliotecas).

## 🚀 Funcionalidades

- ✍️ Editor com preview em tempo real
- 🔧 Parser markdown para HTML implementado do zero
- ⌨️ Atalhos de teclado (Ctrl+B para bold, Ctrl+I para itálico)
- 🎨 Suporte a títulos, listas, código, citações e links
- 📊 Contador de palavras

## 📦 Como usar

Basta abrir o arquivo `index.html` no navegador.

```bash
git clone https://github.com/ScxttZarek/editor-markdown.git
open index.html
```
